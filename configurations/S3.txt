F3-SWITCH
=========

Enterprise Multi-Floor Network
2rd Floor Switch Configuration

enable
configure terminal

hostname F3-SWITCH

! VLAN CONFIGURATION
vlan 10
 name IT
exit

vlan 20
 name ADMIN
exit

! ROUTER CONNECTION - TRUNK
interface fa0/1
 switchport mode trunk
exit

! IT
interface range fa0/2-4
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast
exit

! ADMIN
interface range fa0/5-6
 switchport mode access
 switchport access vlan 20
 spanning-tree portfast
exit

end
write memory

! Verification
show vlan brief
show interfaces trunk
